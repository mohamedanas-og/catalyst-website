# CATALYST — Crop Disease Detection

This is the deployable frontend prototype.

## Run locally
Open `index.html` in a modern browser.

## Deploy
Upload the contents of this folder to a static hosting service such as Vercel, Netlify, or GitHub Pages.

## Important
The current disease analysis is a mock/demo model: it randomly selects from the diseases defined in the JavaScript. A real ML/API backend still needs to be connected for actual crop-disease detection.
